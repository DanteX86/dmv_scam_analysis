# Test Data Directory

This directory contains sanitized test data used for validating analysis tools and scripts.

## Contents
- Sample phishing emails (sanitized)
- Mock DMV document templates
- Test case datasets
- Validation data

## Usage Guidelines
- All test data must be sanitized versions of real data
- No personally identifiable information (PII) should be included
- Data should be clearly marked as test/sample data
- Version control all test datasets

## Security Notes
- Regularly validate that no sensitive data has been accidentally committed
- Use only synthetic or fully anonymized data
- Document all data sanitization procedures used
