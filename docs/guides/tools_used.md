# Tools Used in DMV Scam Analysis

## Overview

This document details the tools and technologies utilized in the analysis of the DMV impersonation scam campaign. It covers software, libraries, and frameworks employed in the investigation process.

- **Python 3.x**
  - Core Language for scripting and automation
  - Used in data processing, analysis, and visualization

### 2. Database Management

- **SQLite**
  - Data extraction and analysis from iMessage database
  - Queries used for message timeline reconstruction

### 3. Data Manipulation

- **Pandas**
  - Data manipulation and cleaning
  - Utilized for managing datasets and performing analysis

### 4. Data Visualization
